# fhir-hose JWKS

Public signing keys for the ASCEND FHIR connector (SMART Backend Services).
Only public keys live here. Private keys never leave the key store.

- Non-production: https://ascendhit.github.io/fhir-hose-jwks/nonprod/jwks.json
- Production:     https://ascendhit.github.io/fhir-hose-jwks/prod/jwks.json (interim; moves to the connector's own domain once hosted)
